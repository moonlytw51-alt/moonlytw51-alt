# Аскорбинки — сайт клана

Статический сайт на HTML/CSS/JavaScript для GitHub Pages. Сборщик не нужен.

## Публикация
1. Создайте новый репозиторий на GitHub и загрузите туда содержимое архива.
2. Откройте Settings → Pages и выберите GitHub Actions в Build and deployment.
3. Загрузите файлы в ветку main. Сайт будет обновляться при каждом push.
4. Адрес появится в Settings → Pages.

Ссылки Telegram уже настроены. При необходимости замените демонстрационные ники в составе. Цвет акцента меняется на сайте и сохраняется в браузере.
